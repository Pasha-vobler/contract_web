Парсер государственных закупок лекарственных препаратов

Поиск контрактов ЕИС по 44-ФЗ с последующим сбором сведений о препаратах, УПД и поставленных лекарственных препаратах. Результат формируется в Excel.
При установленной галочке поиск выполняется с фильтром ЖНВЛП. Если галочка снята — фильтр ЖНВЛП не применяется.
По умолчанию выполняется полная выгрузка. Программа автоматически проходит все страницы поисковой выдачи ЕИС за выбранный период и останавливается только на последней странице.

Поле «Максимум контрактов» используется только как необязательный лимит для тестовых или сокращённых запусков. Если оно пустое, обрабатываются все найденные контракты.

Значение «Результатов ЕИС на странице» влияет только на количество запросов к поиску: 50 обычно быстрее и не ограничивает полноту выгрузки.
